## 🆕 Новое в версии 1.0.8

- 🌐 **Стабильный сетевой стек TUN (`mixed` / gVisor)**:
  - Сетевой стек виртуального адаптера Wintun переключен на отказоустойчивый `mixed` (встроенный стек Google gVisor).
  - Устранена проблема со сбросом TCP-пакетов в Windows при повышенных привилегиях без фоновой службы `lxd` (DNS работал, но браузеры висели).
  - Предотвращены ложные срабатывания Captive Portal в Firefox (`firefox-portal-detection.com`) и зацикливание маршрутов.
- 🧹 **Полная изоляция кэша WebView2 в `%LOCALAPPDATA%`**:
  - Каталог пользовательских данных движка WebView2 (`WebviewUserDataPath`) зафиксирован в `%LOCALAPPDATA%\VPN\webview2`.
  - Приложение больше не создаёт папки с кэшем (`Crashpad`, `ShaderCache`, `Default`) рядом с файлом `.exe` при запуске из папки «Загрузки» или с Рабочего стола.
- 🛡️ **Поддержка Hysteria 2 Salamander & TLS**:
  - Добавлена полная поддержка обфускации Salamander, гибкая настройка ALPN и флага `insecure` для самоподписанных сертификатов.

## 🆕 Новое в версии 1.0.7

- 🛡️ **WARP Detour (Clean IP / Двойной туннель)**:
  - Выход в сеть через Cloudflare WARP поверх любого подключенного прокси (VLESS, Hysteria 2, Shadowsocks, Trojan). Реальный IP сервера скрыт от целевых сайтов, блокировки датацентров и капчи обходятся автоматически.
  - Быстрое переключение одной кнопкой `WARP Clean IP` прямо в шапке главного экрана.
- ⚡ **Выбор самого быстрого узла**:
  - Автоматическое тестирование и переключение на сервер с наименьшим пингом в один клик из выпадающего меню активного узла или в панели «Серверы».
- 🌐 **Реальный тест веб-задержки (Web Latency)**:
  - Проверка фактического HTTP RTT (код 204) до веб-сервиса через активный туннель вместо поверхностного сетевого рукопожатия.
- ⛔ **Kill Switch (Защита от утечки трафика)**:
  - Мгновенная блокировка сетевых пакетов мимо туннеля при случайном обрыве VPN-соединения до момента его восстановления.
- 🔄 **Фоновое автообновление подписок**:
  - Автоматическая синхронизация списков серверов каждые 24 часа в фоне без прерывания работы.
- 💾 **Резервная копия и восстановление профиля**:
  - Экспорт и импорт всех настроек, подписок, кастомных узлов и правил маршрутизации в один клик через переносимый JSON-файл.
- 📡 **Протокол-ориентированный замер пинга**:
  - Нативный системный ICMP Echo для UDP-протоколов (Hysteria 2 / TUIC) и точный замер чистого TCP RTT для VLESS Reality / XHTTP без зависаний.

## ✨ Основные возможности

### ⚡ Разделение по приложениям (Split Tunneling)
- Полный контроль над тем, какой именно трафик идёт через VPN:
  - **Белый список**: через VPN идут *только* выбранные программы (браузер, мессенджер, игра).
  - **Черный список**: через VPN идёт всё, *кроме* выбранных программ.
  - **Весь трафик (Global)**: весь сетевой стек компьютера направляется через туннель.
  - **Прямой (Bypass)**: прямое подключение без шифрования.
- Автоматически находит запущенные процессы Windows и отображает их системные иконки.
- Возможность вручную добавить любой `.exe` файл через стандартный проводник.

### 🛡️ Cloudflare WARP и WARP Detour (Чистый IP)
- **WARP Detour (Clean IP)**: каскадная маршрутизация трафика прокси через Cloudflare. Зарубежные сервисы (ChatGPT, Claude, Netflix) видят чистый домашний IP без блокировок датацентров.
- **Встроенный генератор**:
  - **AmneziaWG (AWG)**: обход блокировок ТСПУ и DPI за счет добавления настраиваемых мусорных пакетов (`Jc`, `Jmin`, `Jmax`, `S1`–`S4`, `H1`–`H4`).
  - **MASQUE / HTTP/3**: маскировка VPN-трафика под обычный защищённый веб-трафик QUIC (порт 443).
  - Регистрация и генерация рабочих ключей Cloudflare в один клик.
- **Импорт конфигураций**:
  - Загрузка существующих файлов `.conf`, `.wireguard`, `.txt` через окно выбора файла.
  - Прямая вставка текста конфигурации с парсингом AmneziaWG параметров.

### ⚡ Выбор быстрейшего узла и реальный Веб-тест
- **⚡ Лучший узел**: автоматический выбор и переключение на сервер с наименьшей задержкой в один клик из выпадающего меню или панели узлов.
- **🌐 Реальный веб-тест (HTTP 204)**: сквозной замер фактической отдачи трафика через туннель вместо поверхностного TCP-рукопожатия.
- **Протокольно-зависимый пинг**: измерение реального TCP RTT для Reality/TLS и системный ICMP Echo для UDP-протоколов (Hysteria 2 / WireGuard).

### ⛔ Защита от утечек и резервное копирование
- **Kill Switch**: аварийная блокировка интернет-трафика мимо туннеля при разрыве VPN-соединения.
- **Фоновое автообновление подписок**: автоматическая синхронизация списков узлов каждые 24 часа и при запуске.
- **Резервная копия профиля**: экспорт и импорт всех настроек, подписок, узлов и списков в единый `.json` файл.

### 📋 Журнал подключений (Логи ядра в реальном времени)
- Встроенное окно просмотра логов ядра **sing-box** прямо на главном экране.
- **Умная фильтрация шума Windows**: автоматическое скрытие битых системных DNS-проб (NetBIOS, mDNS, проверки шлюза Windows) и попакетного спама сетевых игр (CS2 и др.) — отображаются только реальные ошибки и важные события ядра.
- Фильтры сообщений: *Все*, *Ошибки*, *Предупреждения*.
- Поддержка автоскролла, копирования логов в буфер обмена и очистки журнала в один клик.

### 🌐 Умная маршрутизация и Geo-правила (Домены и IP-подсети)
- **Bypass RU**: автоматический обход блокировок РФ и направление российских сервисов (банки, Госуслуги, VK, маркетплейсы, Кинопоиск) напрямую мимо VPN для максимальной скорости.
- **Поддержка IP и подсетей CIDR**: возможность добавлять списки диапазонов IP-адресов (например, пулы российских IP `178.249.0.0/16` или списки блокировок) с выбором действия: **В туннель (Proxy)** или **Напрямую (Direct)**.
- **Гибкая загрузка списков**:
  - По ссылке (GitHub Raw / прямой URL на `.txt` или `.list`).
  - Из локального файла на диске с удобной кнопкой **«Обзор...»**.
- **AdBlock**: блокировка рекламы, счетчиков и трекеров на уровне DNS.

### 📷 Мульти-импорт по QR-коду
- **С экрана**: удобный снимок экрана или отдельного окна для мгновенного распознавания QR-кода.
- **Из буфера обмена (`Ctrl+V`)**: вставка скриншота или текстовой ссылки одной клавишей.
- **Из файла**: перетаскивание (Drag & Drop) или выбор изображений PNG, JPG, WebP.
- **Через веб-камеру**: прямое сканирование QR-кода с телефона или экрана другого устройства.
- Распознаёт ссылки на отдельные узлы, пачки конфигураций и ссылки на подписки.

### 🚀 Поддержка современных протоколов
- VLESS (Reality, TLS, WebSocket, gRPC, **XHTTP / SplitHTTP, постквантовое шифрование ML-KEM-768**)
- VMess
- Shadowsocks (2022)
- Trojan
- Hysteria 2 / Hy2
- TUIC v5
- WireGuard и AmneziaWG (AWG)

### 📊 Телеметрия, подписки и мониторинг
- **Гибридный виджет подписки**: статусная полоса на главном дашборде и подробная карточка на вкладке серверов (поддержка лимитных и безлимитных квот, даты окончания).
- **Автоматический пин активного узла**: подключенный сервер всегда закрепляется на 1-м месте в списке.
- Живой график скорости с частотой 60 кадров/сек (Download / Upload).
- Высокоточный пинг узлов с понятной цветовой индикацией задержки.
- Интерактивное **дерево сетевых соединений**: группировка по именам запущенных процессов, целевые IP-адреса и скорость каждого соединения.

### ⚙️ Кастомизация и безопасность
- **Кастомный User-Agent и HWID**: тонкая настройка идентификации клиента при обновлении подписок для полной совместимости с серверами.
- **Режим приватности (Privacy Blur)**: скрытие IP-адресов, доменов и ключей на лету для безопасных трансляций и скриншотов.

### 🎨 Дизайн и эргономика
- Интерфейс Material 3 Dark (строгий ритм 16px, гармоничная палитра, оптимизированный контраст шрифтов).
- Сворачивание в системный трей с контекстным меню быстрых действий.

## 🚀 Скачивание и запуск

1. Перейдите на страницу [Релизов](https://github.com/zalupacode228/vibe-vpn/releases/latest).
2. Скачайте свежий файл `VibeVPN-v1.0.8-Windows-x64.exe` (или `VPN.exe`).
3. Запустите приложение.
   > **Примечание**: Требуется Windows 10 или 11 (64-бит). Для создания виртуального сетевого адаптера (`wintun.dll`) требуются права администратора.

## 🛠️ Сборка из исходников

### Требования
- **Go**: `1.22+` или `1.23+` ([golang.org](https://go.dev/dl/))
- **Node.js**: `18+` или `20+` ([nodejs.org](https://nodejs.org/))
- **Wails CLI v2**:
  ```powershell
  go install github.com/wailsapp/wails/v2/cmd/wails@latest
  ```
- **WebView2 Runtime** (установлен по умолчанию в Windows 10 и 11)

### Режим разработки (Live Dev)
Запуск с горячей перезагрузкой изменений фронтенда и Go-бэкенда:
```powershell
git clone https://github.com/zalupacode228/vibe-vpn.git
cd vibe-vpn

wails dev
```

### Сборка production-бинарника
Сборка полностью автономного однофайлового приложения (все ресурсы, иконка и ядро вшиваются внутрь):
```powershell
wails build
```
Готовый исполняемый файл появится по пути:
```
build/bin/VPN.exe
```

```
vibe-go/
├── app.go                 # Контроллер Wails, обработчики диалогов и вызовы Windows API

│   ├── appicon.png        # Фирменная векторная иконка щита (1024x1024)

├── pkg/
│   ├── models/            # Структуры данных (узлы, настройки, гео-правила, подписки)
```
