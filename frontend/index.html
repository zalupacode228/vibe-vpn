DNS и Параметры адаптера

Удаленный DNS (DoH/DoT)
DNS сервер для защищенных запросов через VPN
Локальный DNS
DNS сервер для прямых подключений (по умолчанию: local)
Размер MTU адаптера
Оптимальное значение для стабильного канала (обычно 1400 или 1500)

Параметры подписок и Идентификация

User-Agent подписок
HTTP заголовок клиента при запросе подписок. Некоторые провайдеры требуют v2rayN, ClashMeta или Happ
HWID устройства (Hardware ID)
Идентификатор устройства в заголовках HWID, X-HWID и X-Device-Id для панелей с лимитом устройств (Marzban, 3X-UI)
